# Java OOP Projects

A collection of small Java programs I built while studying **Object-Oriented Programming** as part of my Computer Systems Engineering degree. Each project focuses on a different core concept, from methods and conditionals to inheritance, polymorphism, collections, file I/O and graphical user interfaces.

## Projects

| # | Project | What it does | Key concepts |
|---|---------|--------------|--------------|
| 01 | [Product Pricing](01-product-pricing) | Calculates an order total by product category and shows a 3-month credit payment plan | Classes & objects, methods, `if/else`, loops, `Scanner` input |
| 02 | [Stock Exchange](02-stock-exchange) | Models a stock and calculates its price-change percentage | Constructors, fields, getters/setters, formatted output |
| 03 | [Hospital System](03-hospital-system) | Registers doctors, patients and guards through a common abstract class | Inheritance, abstract classes, polymorphism, constructor overloading, encapsulation |
| 04 | [Melate Lottery](04-melate-lottery) | Generates 7 unique random lottery numbers and saves them to a text file | `ArrayList`, `Random`, file writing, exception handling |
| 05 | [Captcha (Swing)](05-captcha-swing) | Desktop app that draws a distorted CAPTCHA and validates the user's input | Swing GUI, event listeners, `Graphics2D` drawing |

## Requirements

- Java Development Kit (JDK) 17 or newer

## How to run

Each project is independent. From the project folder:

```bash
cd 01-product-pricing/src
javac Product.java
java Product
```

See each project's README for its specific instructions.
